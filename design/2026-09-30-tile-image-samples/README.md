# 第一批 image 牌面样板

2026-09-30。五筒、三索、伍萬、東四张正式候选样板，来自内置 image_gen，逐张生成； approved-reference.png 为用户确认的美术方向。

## 交付

- originals/：未修改的透明底高清生成原图。
- ../../assets/tiles/engraved-v1/：小程序已接入的四张透明 PNG，统一 192×264，合计 356327 bytes（约 348 KiB）。
- prompts.json：四次生成的完整提示词。
- export.swift / export-report.json：原图透明通道检查、外部留白裁切、尺寸统一及导出记录；无重新绘制牌纹。
- preview.png / index.html：大图与小尺寸验收；标注尺寸以 375px 屏宽换算，不代表聊天中图片显示的物理像素。
- screens/：微信开发者工具实际截图。01、02 为万/筒选牌区；03、04 为索/字；05 为五筒已用尽；06 为最终验收。

## 接入

components/tile 按 ID 4、13、20、27 加载完整牌身 PNG，移除重复的 CSS 牌身阴影。保留和了牌外框、暗杠变暗、禁用透明度及按下反馈。赤五继续使用原有素材，避免普通五被误用于赤五。

本轮仅替换四种普通牌；其余牌面尚未制作，因此选牌器暂时混用两套风格。
