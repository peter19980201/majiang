# 六至九筒传统连纹修订

根据用户提供的实体麻将照片，使用 image_gen 逐张重画六至九筒。照片只用于布局，颜色保留此前 AMOS 参考的蓝黑与朱红，不使用照片中的绿色。一至五筒保持原样。

- 六筒：上方两个蓝黑圆纹相接，下方四个红圆纹相接，两组之间保留明显留白。
- 七筒：上方三个蓝黑圆纹沿斜线相接，下方四个红圆纹组成相接方阵。
- 八筒：八个蓝黑圆纹，两列四行紧密相接。
- 九筒：上黑、中红、下黑，每排三个圆纹相接，排与排之间保留间隔。

整体增大圆纹，保持象牙白牌身与传统雕刻填色风格。此前强行缩小圆纹、增加组内间距的处理已废弃。
