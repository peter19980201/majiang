# 索子补全

使用内置 image_gen，逐张生成一、二、四至九索及赤五索。已批准的三索保持原样。原始图在 `originals/`，完整提示词在 `prompts.json`。

布局与配色核对：[AMOS 官方麻将牌介绍](https://shop.taiyo-chemicals.co.jp/blog/?p=1288)。风格使用已批准的 `design/2026-09-30-tile-image-samples/originals/sou-3.png`。一、八、九索额外使用官方小图锁定形状与数量，保存于 `references/`。

- 一索：传统孔雀，深绿雕刻、红嘴红脚。
- 二索：上下各一根深绿竹节。
- 四索：两列两排，均为深绿。
- 五索：四角深绿，中心红色。
- 六索：三列两排，均为深绿。
- 七索：顶端一红，下方两排、每排三绿。
- 八索：四根外侧竖杆与四根内侧斜杆组成上下对向的连接纹样，均深绿。
- 九索：三列三排，每排为绿红绿，中心列红色。
- 赤五索：五根全红，沿用普通五索位置。

已逐张目视检查数量、颜色、排列。九索第一版误生成六根，已拒收为 `sou-9-rejected-six-rods.png`；第二版正确九根，用于导出。

`export.swift` 复用已批准素材的机械裁切规范，以牌身不透明像素统计去除外侧零碎点，保留透明背景，导出 192×264 PNG 到 `assets/tiles/engraved-v1/`。未做颜色量化或有损转换；导出尺寸、透明像素与体积记录在 `export-report.json`。没有修改组件代码。
